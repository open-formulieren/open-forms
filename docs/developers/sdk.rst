.. _developers_sdk:

==============
Javascript SDK
==============

The `Javascript SDK`_ is built to :ref:`embed forms <developers_embedding>` in various
types of pages. It is used internally in the Open Forms project for the public UI
functionality.

.. note:: Maintainers of the SDK should look for SDK documentation in Storybook_.

.. _Storybook: https://open-formulieren.github.io/open-forms-sdk/
