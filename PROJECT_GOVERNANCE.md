# Project Governance

The fundamental principle is that decisions are based on consensus within the 
community. If a decision-making process takes too long or a decision is urgently
required, the "Steering Committee" has the authority to make 
decisions.

## Steering Committee

The Steering Committee (SC) is responsible for:

1. The general ambitions and objectives of this project
2. Guidelines, procedures, and tool selection
3. Decisions regarding information/enterprise architecture
4. Raising issues relevant to the direction and development of this project

## Maintainers

Maintainers are responsible for maintaining parts of the codebase. Maintainers 
have the following responsibilities (summary):

* Coordinating development activities
* Ensuring code and documentation reviews are performed
* Coordinating Pull Requests
* Coordinating security issues and bug report follow-ups
* Coordinating responses to inquiries
* In the event of prolonged discussions or disputes, maintainers (among others)
  may request a decision from the SC.

The current maintainer of this project is [Maykin](https://www.maykin.nl). For
more in-depth information about the tasks, activities, responsibilities and 
financing, please see
[Broncodebeheer](https://maykinmedia.github.io/maykin-plus/broncodebeheer).

Any community member or contributor can ask a question or report an issue by
opening a GitHub issue (see the [Contribution Guide](CONTRIBUTING.md)).

## Contributors

"Contributors" refers to anyone in the community who contributes code, 
documentation, or other useful artifacts to the project.

Anyone can become a contributor.

There is no expectation of commitment to the project, no specific skill 
requirements, and no selection process. To become a contributor, a community 
member simply needs to perform one or more actions that benefit the project.
